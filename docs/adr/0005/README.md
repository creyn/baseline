# Figures of ADR-0005: historical, not current

These three figures compared the import variants for the decision in [ADR-0005](../0005-asynchronous-import-pipeline.md), accepted on 2026-11-23. They show the design as it was then. They are kept unchanged as the record of that decision and are no longer current.

Later decisions changed the import (for example the extraction contracts, the dates for trends and the unread results of ADR-0018). The current import is [docs/sequences/02-import.svg](../../sequences/02-import.svg), described in [docs/sequences](../../sequences/README.md).

The figures are not generated again. [tools/diagrams/import-variants.js](../../../tools/diagrams/import-variants.js) made them, but it reads the shared steps of the current diagrams, so running it now would draw today's design into an accepted ADR.
